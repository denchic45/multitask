Справочник API (API Reference)
===============================

Пакет: ``threads`` (псевдоним: ``th``)

Условия ошибок (Conditions)
---------------------------

``base-error``
  *Тип*: ``condition`` (наследует от ``cl:error``)
  Базовое условие для всех ошибок.
  Читатель: ``base-error-message``.

``not-implemented-error``
  *Тип*: ``condition`` (наследует от ``base-error``)
  Сигнализируется при обращении к нереализованным операциям.
  Читатель: ``not-implemented-feature-name``.

``thread-error``
  *Тип*: ``condition`` (наследует от ``base-error``)
  Сигнализируется при аварийном завершении выполнения зеленого потока.
  Читатель: ``thread-error-thread``.

``timeout-error``
  *Тип*: ``condition`` (наследует от ``base-error``)
  Сигнализируется при превышении таймаута в операциях ожидания.

Зеленые потоки (Threads)
------------------------

``thread``
  *Тип*: ``struct`` Структура зеленого потока. Селекторы:

  * ``thread-id`` – числовой идентификатор;
  * ``thread-name`` – строковое или символьное имя;
  * ``thread-state`` – статус (``:created``, ``:runnable``, ``:running``, ``:waiting``, ``:dead``);
  * ``thread-result`` – результат вычисления.

``thread-p (object)``
  *Тип*: ``function``
  Предикат проверки структуры ``thread``.

``thread-spawn (function &key name)``
  *Тип*: ``function``
  Создает новый зеленый поток и запускает его выполнение.
  Возвращает объект ``thread``.

``thread-yield ()``
  *Тип*: ``function``
  Добровольно уступает процессор, позволяя другим потокам выполниться.

``current-thread ()``
  *Тип*: ``function``
  Возвращает зеленый поток, выполняющийся в данный момент.

``thread-wait (thread &key timeout)``
  *Тип*: ``function``
  Блокирует текущий поток до завершения целевого ``thread`` и возвращает его результат.

``thread-kill (thread)``
  *Тип*: ``function``
  Принудительно переводит поток в статус ``:dead``.

``thread-alive-p (thread)``
  *Тип*: ``function``
  Возвращает ``T``, если поток еще не завершил свое выполнение.
