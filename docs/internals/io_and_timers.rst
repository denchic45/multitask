Вввод-вывод и таймеры
===================================================

Назначение
---------------------

Подсистема обеспечивает асинхронное ожидание событий времени (``thread-sleep``) и файловых дескрипторов (``wait-fd-read``, ``wait-fd-write``) без блокирования системного потока операционной системы.

Организация таймеров
-------------------------------

1. **Структура хранения**:
   таймеры упорядочиваются в двоичной куче по абсолютному значению дедлайна монотонных часов.

2. **Проверка наступления дедлайнов**:
   планировщик сверяет текущее монотонное время со значением в корне кучи. Потоки с истекшим интервалом извлекаются из структуры, переводятся из состояния ``:waiting`` в ``:runnable`` и возвращаются в Run Queue.

Цикл событий
----------------------------------------------

При отсутствии потоков, готовых к исполнению в Run Queue, планировщик выполняет блокирующее ожидание событий:

1. **Расчет интервала ожидания**: вычисление разницы между ближайшим дедлайном таймера в куче и текущим монотонным временем (значение :math:`T`).
2. **Вызов мультиплексора**: выполнение системного вызова ``epoll_wait(..., timeout = T)``.
3. **Обработка событий ядра**: разблокирование системного потока при поступлении событий ввода-вывода либо по истечении интервала :math:`T`.
4. **Диспетчеризация**: потоки с наступившими событиями дескрипторов и истекшими таймерами переводятся в состояние ``:runnable`` и помещаются в Run Queue.
