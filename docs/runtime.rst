Среда выполнения (Runtime и Планировщик)
========================================

Понятие среды выполнения
------------------------

Среда выполнения (структура ``runtime``) представляет собой экземпляр планировщика задач и ассоциированных с ним ресурсов:

* очередь готовых к выполнению задач (Run Queue);
* таблица зарегистрированных задач;
* пул системных рабочих потоков (для многопоточного планирования).

Жизненный цикл среды выполнения
-------------------------------

Использование через макрос ``with-runtime``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Рекомендуемым способом работы со средой выполнения является макрос ``with-runtime``. Он гарантирует корректную инициализацию планировщика, привязку к динамической переменной ``*runtime*`` и обязательную остановку при выходе из блока (посредством ``unwind-protect``):

.. code-block:: common-lisp

   (multitask:with-runtime (:workers 2)
     ;; Внутри блока *runtime* указывает на активный экземпляр
     (format t "Рантайм активен: ~a~%" (multitask:runtime-running-p))
     
     (multitask:spawn
      (lambda ()
        (format t "Выполнение внутри рантайма~%"))))

Ручное управление: ``start-runtime`` и ``stop-runtime``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

В ситуациях, когда требуется долгоживущий глобальный планировщик, запуск и остановка могут выполняться вручную:

.. code-block:: common-lisp

   (defvar *my-rt* (multitask:start-runtime :workers 4))

   ;; Проверка состояния
   (when (multitask:runtime-running-p *my-rt*)
     (format t "Планировщик запущен~%"))

   ;; Остановка планировщика
   (multitask:stop-runtime *my-rt*)

Параметры планировщика
----------------------

* ``:workers`` (целое число, по умолчанию 1) — определяет количество рабочих потоков операционной системы.
  При значении `1` планирование является полностью однопоточным (1:N), что исключает необходимость в сложных блокировках.
  При значении `> 1` активируется M:N планировщик с распределением задач между рабочими потоками.

Динамический контекст: ``*runtime*``
------------------------------------

Специальная переменная ``*runtime*`` хранит текущий активный контекст рантайма в вызывающем потоке. Большинство функций управления задачами и синхронизации обращаются к ``*runtime*`` по умолчанию, если экземпляр не передан явно.
