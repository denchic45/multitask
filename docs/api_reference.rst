Справочник API (API Reference)
===============================

Пакет: ``multitask`` (псевдоним: ``mt``)

Условия ошибок (Conditions)
---------------------------

``multitask-error``
  *Тип*: ``condition`` (наследует от ``cl:error``)
  Базовое условие для всех ошибок библиотеки Multitask.
  Читатель: ``multitask-error-message``.

``not-implemented-error``
  *Тип*: ``condition`` (наследует от ``multitask-error``)
  Сигнализируется при обращении к нереализованным операциям.
  Читатель: ``not-implemented-feature-name``.

``task-error``
  *Тип*: ``condition`` (наследует от ``multitask-error``)
  Сигнализируется при аварийном завершении выполнения зеленого потока.
  Читатель: ``task-error-task``.

``timeout-error``
  *Тип*: ``condition`` (наследует от ``multitask-error``)
  Сигнализируется при превышении таймаута в операциях ожидания.

Среда выполнения (Runtime)
--------------------------

``*runtime*``
  *Тип*: ``variable``
  Текущий активный экземпляр среды выполнения (планировщика).

``runtime``
  *Тип*: ``struct``
  Структура данных среды выполнения и планировщика.

``runtime-p (object)``
  *Тип*: ``function``
  Предикат проверки, является ли объект экземпляром ``runtime``.

``runtime-running-p (&optional (rt *runtime*))``
  *Тип*: ``function``
  Возвращает ``T``, если среда выполнения ``rt`` активна и обрабатывает задачи.

``start-runtime (&key (workers 1))``
  *Тип*: ``function``
  Инициализирует и запускает среду выполнения с указанным количеством рабочих потоков.
  Возвращает объект ``runtime``.

``stop-runtime (&optional (rt *runtime*))``
  *Тип*: ``function``
  Останавливает планировщик.

``with-runtime ((&key (workers 1)) &body body)``
  *Тип*: ``macro``
  Выполняет блок кода ``body`` в изолированном контексте ``*runtime*`` с гарантированной остановкой планировщика при выходе.

Задачи (Tasks)
--------------

``task``
  *Тип*: ``struct``
  Структура зеленого потока. Селекторы:
  * ``task-id`` — числовой идентификатор;
  * ``task-name`` — строковое или символьное имя;
  * ``task-state`` — статус (``:created``, ``:runnable``, ``:running``, ``:waiting``, ``:dead``);
  * ``task-result`` — результат вычисления.

``task-p (object)``
  *Тип*: ``function``
  Предикат проверки структуры ``task``.

``spawn (function &key name (stack-size 65536))``
  *Тип*: ``function``
  Создает новый зеленый поток и планирует его выполнение.
  Возвращает объект ``task``.

``yield-task ()``
  *Тип*: ``function``
  Добровольно передает управление планировщику, позволяя другим задачам выполниться.

``current-task ()``
  *Тип*: ``function``
  Возвращает задачу, выполняющуюся в данный момент.

``join-task (task &key timeout)``
  *Тип*: ``function``
  Блокирует текущую задачу до завершения целевой ``task`` и возвращает ее результат.

``kill-task (task)``
  *Тип*: ``function``
  Принудительно переводит задачу в статус ``:dead``.

``task-alive-p (task)``
  *Тип*: ``function``
  Возвращает ``T``, если задача еще не завершила свое выполнение.

Примитивы синхронизации (Synchronization)
-----------------------------------------

``mutex``
  *Тип*: ``struct``
  Структура мьютекса.

``mutex-p (object)``
  *Тип*: ``function``
  Предикат проверки структуры ``mutex``.

``make-mutex (&key name)``
  *Тип*: ``function``
  Создает новый мьютекс.

``acquire-mutex (mutex &key timeout)``
  *Тип*: ``function``
  Захватывает мьютекс для текущей задачи или блокирует ее до освобождения.

``release-mutex (mutex)``
  *Тип*: ``function``
  Освобождает мьютекс и пробуждает следующую ожидающую задачу.

``with-mutex ((mutex &key timeout) &body body)``
  *Тип*: ``macro``
  Идиоматичный захват и освобождение мьютекса вокруг блока кода.

``condition-variable``
  *Тип*: ``struct``
  Структура условной переменной.

``condition-variable-p (object)``
  *Тип*: ``function``
  Предикат проверки условной переменной.

``make-condition-variable (&key name)``
  *Тип*: ``function``
  Создает новую условную переменную.

``wait-condition-variable (cv mutex &key timeout)``
  *Тип*: ``function``
  Освобождает мьютекс и переводит задачу в ожидание уведомления по условной переменной ``cv``.

``notify-condition-variable (cv)``
  *Тип*: ``function``
  Пробуждает одну задачу, ожидающую на ``cv``.

``notify-all-condition-variables (cv)``
  *Тип*: ``function``
  Пробуждает все задачи, ожидающие на ``cv``.

Таймеры и I/O (Timers & I/O)
----------------------------

``task-sleep (seconds)``
  *Тип*: ``function``
  Приостанавливает задачу на указанное время в секундах без блокировки системного потока.

``wait-fd-read (fd &key timeout)``
  *Тип*: ``function``
  Кооперативно ожидает готовности дескриптора ``fd`` к чтению.

``wait-fd-write (fd &key timeout)``
  *Тип*: ``function``
  Кооперативно ожидает возможности записи в дескриптор ``fd``.
